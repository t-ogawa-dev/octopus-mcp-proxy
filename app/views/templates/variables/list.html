💡 Variablesの使用方法 ▼

変数をアプリやCapabilityで使用するには {{VARIABLE_NAME}} の形式で参照してください

📍 使用可能な箇所:
  • Capability接続先URL: APIエンドポイントのURL
  • アプリ共通ヘッダー: 全Capabilityで使用されるヘッダー値
  • Capability個別ヘッダー: 特定Capabilityのヘッダー値
  • Capabilityボディパラメータ: リクエストボディの値
  • Capabilityテンプレートコンテンツ: Promptタイプのテンプレート内
✏️ 使用例:
// 接続先URL
"https://api.example.com/{{API_KEY}}"
// アプリ共通ヘッダー
"Authorization": "Bearer {{OPENAI_API_KEY}}"
// Capabilityヘッダー
"X-API-Key": "{{CUSTOM_API_KEY}}"
// ボディパラメータ
"api_key": "{{SERVICE_KEY}}",
"user": "{{USER_ID}}"
